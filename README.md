# 教务助手（HAUEJW）

河南工程学院教务系统的第三方安卓客户端，Kotlin + Jetpack Compose，单 APK 约 1.3 MB。

> 非官方项目，与河南工程学院无隶属关系。仅供个人学习自用，禁止商业用途与二次分发。详见 [NOTICE.md](NOTICE.md)。

## 功能

- **课表**：按周显示，左右滑动切换周次，也可用箭头或周次条；支持单双周、集中实践课；点课程卡片看教师、教室、学分、考核等详情；本地缓存，断网时可看上次加载的
- **课前提醒**：每节课开课前 10/20/30/45 分钟提醒，两周内的课自动排好，重启手机后自动重排。可选普通消息通知，或整屏闹钟（静音也会响、自动亮屏）
- **成绩与考试**：读取教务系统接口；成绩面板顶部有加权 GPA、加权平均分、学分进度汇总，并可「累计全部学期」算总 GPA
- **桌面小组件**：一张卡片显示今天课表、下一节课、学期进度与距放假天数、今天还剩几节。拖窄到 2×2 时只留「今天还剩几节」和「下一节」，拖回大尺寸恢复完整卡片；可在应用内固定画法（自动 / 4×2 详细 / 2×2 简版）或整个关闭，面板显示桌面那张现在是几格；数据取自本机缓存，断网也能显示。桌面上的尺寸只能长按卡片拖动，应用无权修改
- **回声洞**：小组件底部一块自定义文字区，轮流显示自己写的话。换句时先播约半秒的机器故障闪断，整句显示完整后停 5 秒换下一条，一轮内不重复；长句自动缩字号，组件拖高可放更大的字
- **回声洞内容**：写在 jwzs.txt 里，格式 `"内容";`，引号内为正文，分号或换行断句，中英文引号与分号都认，不写引号则整句显示。可在应用内「常用功能 → 回声洞 → 编辑内容」直接修改。想把自己的句子并入默认内容，改 `app/src/main/assets/jwzs.txt` 提 PR
- **本地修改**：可改课程显示名、把某次课从某一周或本学期移除、调整上课时间（单次或整学期）。改动只存本机，不影响教务系统数据，可随时撤销
- **导入导出**：课表支持 JSON、CSV、ICS 导入（按内容自动识别），可导出为 JSON 或图片
- **切换账号**：课表页右上角「切换」直接换账号，无需先退出；课表缓存、保存时间、来源、本地修改、导入的课表按账号各存一份；密码按学号分开加密存放，删一个不影响其他
- **电费查询**：常用功能 → 生活 → 电费查询。首次在应用内打开学校的校园卡门户登录（学号、密码、验证码都在学校页面上输入），登录后选一次宿舍房间（校区 → 楼栋 → 楼层 → 房间），选定后记在本机，之后打开面板直接显示剩余电量，打开面板不联网，要新的点「立即查询」。只查询，不缴费
- **电费定时查询与预警**：可设每天一个时刻自动查一次，结果存本机，面板显示上次值与查询时间；可设余额预警值，查到低于该值时发一条通知（每天最多一条）。学校系统 23:00–03:00 不开放查询，时刻设在这一段的自动顺延到 03:05。定时查询失败（如登录过期）也会通知。时刻用拨轮选择，拖动即改
- **校园卡状态随账号清理**：退出并清除缓存、重新登录、以及余额面板里的「忘记登录」，都会清掉本机的校园卡凭据、上次读数、房间与预警设置，定时查询一并取消。本机存多个学号时各存各的：凭据、房间、上次读数、预警、定时时刻都按学号分开，定时查询各排各的闹钟。定时查询用闹钟唤醒，进程被杀不影响；另有 6 小时一次的看门狗，配合开机、升级、插拔电源、改系统时间四个时机把闹钟重新挂上，本机记着「下次该查的时刻」，漏掉的会在下次打开应用时补查一次（23:00–03:00 不补）
- **外观**：浅色、深色两套主题

## 运行要求

- Android 8.0（API 26）及以上，目标 API 35
- 能访问学校教务系统 `http://124.system.haue.edu.cn/jwglxt/`
- 用电费查询时需能访问学校校园卡平台 `http://card.mp.haue.edu.cn/`

## 下载

到 [Releases](../../releases) 下载最新的 `HAUEJW-<版本>.apk`，传到手机安装。

APK 使用个人签名（CN=HAUEJW）。安卓提示「未知来源」时，在系统设置里允许安装。

## 隐私与安全

- 账号密码只在本机保存：记住密码用 Android Keystore 派生密钥做 AES-GCM 加密；登录会话不落盘，过期时用本机保存的密码自动重登
- 桌面小组件只放桌面、不进锁屏，卡片上不含姓名学号
- 无统计分析、无广告、无第三方追踪，不上传任何数据
- 明文 HTTP 只对学校域名放行，其它一律禁止
- 校园卡登录同样在学校自己的网页里完成，应用不接触密码与验证码；查询凭据用 AES-GCM 加密存本机（密钥在系统密钥库），按学号分开存放
- 只读取数据（课表、成绩、考试、电费），不向学校系统提交任何修改

## 自己编译

```bash
cd HAUEJW
./gradlew.bat assembleDebug      # 调试包，可与正式版共存
./gradlew.bat assembleRelease    # 正式包（R8 压缩，需要 keystore.properties）
```

签名密钥不在仓库里（`.gitignore` 已排除 `keystore/` 与 `keystore.properties`）。自己编译正式包时准备一份自己的即可：

```properties
storeFile=keystore/你的.jks
storePassword=你的口令
keyAlias=你的别名
keyPassword=你的口令
```

Windows 上 release 报 `classes.dex 另一个程序正在使用` 时：`./gradlew.bat --stop`，删掉 `app/build/intermediates/dex/release` 再构建。

## 代码结构

| 文件 | 作用 |
|---|---|
| `JwApi.kt` | 接口：登录、课表、成绩、考试、会话、自检 |
| `Models.kt` | 数据模型 |
| `WeekUtils.kt` | 周次与节次解析、周↔日期换算、节次时间表 |
| `Semester.kt`、`Gpa.kt` | 学期进度、加权 GPA 与学分统计 |
| `Widget.kt`、`WidgetState.kt` | 桌面小组件：渲染与刷新、卡片内容与尺寸自适应 |
| `Echo.kt`、`assets/jwzs.txt` | 回声洞：语句解析、故障帧、随机挑句与换句节奏 |
| `Reminder.kt`、`AlarmActivity.kt` | 课前提醒、整屏闹钟 |
| `Scores.kt`、`Exams.kt` | 成绩（含 GPA 汇总卡、累计全部学期）、考试信息 |
| `Edits.kt`、`ImportExport.kt` | 本地修改、课表导入导出（JSON/CSV/ICS） |
| `TimetableImage.kt` | 课表导出图片 |
| `Prefs.kt`、`SecretStore.kt` | 本地存储、密码加密存储 |
| `CardFee.kt`、`CardLoginActivity.kt` | 电费查询：门户登录换查询凭据、费项、逐级选房间、查电表读数 |
| `CardWatch.kt` | 电费定时查询与余额预警：闹钟排期、本地缓存、通知 |
| `WheelPicker.kt` | 拨轮选择器（时:分） |
| `Theme.kt` | 配色 |
| `Diag.kt` | 本地诊断（只记位置与异常类名，不记内容） |
| `MainActivity.kt`、`Board.kt`、`Panes.kt` | 入口、课表界面主体、各设置面板（常用功能、小组件、回声洞设置与内容编辑等） |

单元测试在 `app/src/test/`，135 个，覆盖课表解析、周次换算、学期进度、GPA、小组件内容与尺寸、卡片形态与格数换算、回声洞解析与换句、提醒排程、诊断、账号隔离、校园卡费项与电表读数解析。
