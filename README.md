# 教务助手（HAUEJW）

河南工程学院教务系统的第三方安卓客户端，Kotlin + Jetpack Compose，单 APK 约 1.3 MB。

> 非官方项目，与河南工程学院无隶属关系。仅供个人学习自用，禁止商业用途与二次分发。详见 [NOTICE.md](NOTICE.md)。

## 功能

- **课表**：按周显示，**左右滑动即可切换周次**，也可用箭头或周次条；支持单双周、集中实践课；点课程卡片看教师、教室、学分、考核等详情；本地缓存，进不去校园网也能看上次的
- **课前提醒**：每节课开课前 10/20/30/45 分钟提醒，两周内的课自动排好，重启手机后自动重排。可选普通消息通知，或整屏闹钟（静音也会响、自动亮屏）
- **成绩与考试**：直接读教务系统接口；成绩面板顶部有加权 GPA、加权平均分、学分进度汇总，还能「累计全部学期」算总 GPA
- **桌面小组件**：今天课表、下一节课、学期进度与距放假天数、今天还剩几节，都在一张卡片上；**拖窄到 2×2 自动只留「今天还剩几节」和「下一节」，拖回大尺寸恢复完整卡片**；数据取自本机缓存，断网也能显示。常用功能里点「添加桌面小组件」即可添加
- **回声洞**：小组件底部一块自定义文字区，轮流显示你自己写的话。换句时先播约半秒的机器故障闪断，整句显示完整后停 5 秒换下一条；长句自动缩字号，把组件拖高能放更大的字
- **回声洞内容**：写在自己的 `jwzs.txt` 里，格式 `"内容";`——引号里是正文，分号或换行断句，中英文引号和分号都认，不写引号整句照显。App 内「常用功能 → 回声洞」可直接编辑。想把自己的句子并进默认内容，改 `app/src/main/assets/jwzs.txt` 提 PR
- **本地修改**：可在手机上改课程显示名、把某次课从某一周或本学期移除、调整上课时间（只改一次或整学期）。改动只存本机，不影响教务系统数据，可随时撤销
- **导入导出**：课表支持 JSON、CSV、ICS 导入（按内容自动识别），可导出为 JSON 或图片
- **切换账号**：课表页右上角「切换」直接换账号，不用先退出；每个账号的课表缓存、保存时间、来源、本地修改、导入的课表各存一份；密码按学号分开加密存放，删一个不影响其他
- **外观**：浅色、深色两套主题

## 运行要求

- Android 8.0（API 26）及以上，目标 API 35
- 能访问学校教务系统 `http://124.system.haue.edu.cn/jwglxt/`

## 下载

到 [Releases](../../releases) 下载最新的 `HAUEJW-<版本>.apk`，传到手机安装即可。

APK 使用个人签名（CN=HAUEJW）。安卓提示「未知来源」时，在系统设置里允许安装即可。

## 隐私与安全

- 账号密码只在本机保存：记住密码用 Android Keystore 派生密钥做 AES-GCM 加密；登录会话不落盘，过期时用本机保存的密码自动重登
- 桌面小组件只放桌面、不进锁屏，卡片上不含姓名学号
- 不上传任何东西：没有统计分析、没有广告、没有第三方追踪
- 明文 HTTP 只对学校域名放行，其它一律禁止
- 应用只读取数据（课表、成绩、考试），不向学校系统提交任何修改

## 自己编译

```bash
cd HAUEJW
./gradlew.bat assembleDebug      # 调试包，可与正式版共存
./gradlew.bat assembleRelease    # 正式包（R8 压缩，需要 keystore.properties）
```

发布用的签名密钥不在仓库里（`.gitignore` 已排除 `keystore/` 与 `keystore.properties`）。自己编译正式包时准备一份自己的即可：

```properties
storeFile=keystore/你的.jks
storePassword=你的口令
keyAlias=你的别名
keyPassword=你的口令
```

Windows 上 release 报 `classes.dex 另一个程序正在使用` 时：`./gradlew.bat --stop`，删掉 `app/build/intermediates/dex/release` 再构建。

## 代码结构

| 文件 | 作用 |
|---|---|
| `JwApi.kt` | 接口：登录、课表、成绩、考试、会话、自检 |
| `Models.kt` | 数据模型 |
| `WeekUtils.kt` | 周次与节次解析、周↔日期换算、节次时间表 |
| `Semester.kt`、`Gpa.kt` | 学期进度、加权 GPA 与学分统计 |
| `Widget.kt`、`WidgetState.kt` | 桌面小组件：渲染与刷新、卡片内容与尺寸自适应 |
| `Echo.kt`、`assets/jwzs.txt` | 回声洞：语句解析、故障帧、随机挑句与换句节奏 |
| `Reminder.kt`、`AlarmActivity.kt` | 课前提醒、整屏闹钟 |
| `Scores.kt`、`Exams.kt` | 成绩（含 GPA 汇总卡、累计全部学期）、考试信息 |
| `Edits.kt`、`ImportExport.kt` | 本地修改、课表导入导出（JSON/CSV/ICS） |
| `TimetableImage.kt` | 课表导出图片 |
| `Prefs.kt`、`SecretStore.kt` | 本地存储、密码加密存储 |
| `Theme.kt` | 配色 |
| `Diag.kt` | 本地诊断（只记位置与异常类名，不记内容） |
| `MainActivity.kt`、`Board.kt`、`Panes.kt` | 入口、课表界面主体、各设置面板 |

单元测试在 `app/src/test/`，103 个（课表解析、周次换算、学期进度、GPA、小组件内容与尺寸自适应、回声洞解析/挑句/换句节奏/容量截断、提醒排程、诊断、账号隔离）。
