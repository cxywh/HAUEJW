# 教务助手（HAUEJW）开发文档

河南工程学院教务系统的安卓客户端。Kotlin + Jetpack Compose，单 APK 约 1.3 MB。

- 包名：`com.cxywh.hauejw`（debug 版带 `.debug` 后缀，可与正式版共存）
- 版本：0.2.1（versionCode 58，对外版本号单调递增）
- minSdk 26（Android 8.0+，要用 `java.time`），targetSdk 35
- 站点：`http://124.system.haue.edu.cn/jwglxt/`（全站明文 HTTP，只对它放行）

---

## 一、三条必须先懂的约定

1. **账号私有数据一律走 `Prefs.key()` 作用域键**。键名基名集中写在 `Prefs.ACCOUNT_SCOPED_KEYS`（`tt` / `ttAt` / `src` / `edits` / `imported`）——**加新的账号数据时，必须同时加进这个清单**，否则老版本那套单账号数据迁移会漏掉它，用户升级后看到「明明登录了却没有课表」。有一条单测钉着这件事。
2. **课表页和桌面小组件读同一份数据**（`Prefs.loadBase()` 再套 `prefs.edits`）。任何一端改了数据，都要让另一端刷新：App 侧调 `HaueWidget.refresh(ctx)`，账号边界（登录 / 切号 / 退出）在 `Root` 里显式调（那条路可能走不到课表页）。
3. **纯逻辑不许碰 Android API**。周次换算、学期进度、GPA、小组件内容、编辑层、导入导出都在纯函数里，能直接在 JVM 上跑单测（`./gradlew.bat testDebugUnitTest`）。界面和 RemoteViews 组装不写逻辑 —— 那部分测不了，只能靠真机截图。

## 二、模块与数据流

```
登录 ──► JwApi(会话, CookieManager)
          │
          ├─► Prefs(按账号缓存课表 JSON + 校历起止)
          │        │
          │        ├─► Board.kt 课表界面 ──┐
          │        ├─► Reminder.kt 课前提醒 │  都消费同一份缓存
          │        └─► Widget.kt 桌面小组件 ┘
          │
          └─► Scores.kt / Exams.kt（实时查询，不落盘）
```

| 文件 | 作用 |
|---|---|
| `JwApi.kt` | 接口层：登录（RSA 加密提交）/ 校历 / 课表 / 会话 / 网络自检 |
| `Models.kt` | `Course` / `Term` / `Timetable` / `Student`；`Timetable.coursesOf(week, day)` 是查课入口 |
| `WeekUtils.kt` | 节次表 `Slots.ALL`（唯一真值来源）、`WEEK_LABELS`、周↔日期换算 |
| `Semester.kt` | 学期进度（第几周 / 已过百分比 / 距放假天数）、今天还剩几节、正在上哪节、下一节（可跨周） |
| `Gpa.kt` | 加权 GPA / 加权平均分 / 学分统计（数字格式化固定 `Locale.US`，避免地区差异显示成 `3,42`） |
| `WidgetState.kt` | 小组件「该显示什么」的纯函数（详细版 `widgetState` + 2×2 `smallState`）——可单测，渲染层只负责上色 |
| `Widget.kt` | 小组件：RemoteViews 渲染 + 尺寸分支 + 开关与形态 + 刷新调度 + 「添加到桌面」入口 |
| `Echo.kt` | 回声洞：jwzs.txt 解析、故障帧、随机挑句、换句节奏；容量上限也在这里 |
| `Board.kt` | 课表界面主体（状态机 + 登录流 + 网格 + 底部栏 + 面板分发） |
| `Panes.kt` | 各设置面板（常用功能按分组铺卡片、小组件、回声洞设置与内容编辑、周次、主题、提醒、本地修改、账号等） |
| `Scores.kt` / `Exams.kt` | 成绩（含 GPA 汇总卡、累计全部学期）/ 考试信息 |
| `Reminder.kt` | 课前提醒：通知渠道 + `AlarmManager` 精确闹钟 + 开机重排 + 自包含待发清单 |
| `AlarmActivity.kt` | 整屏闹钟界面 |
| `Edits.kt` / `ImportExport.kt` | 本地修改层 / 课表 JSON·CSV·ICS 导入导出 |
| `TimetableImage.kt` | 课表导出图片 |
| `Prefs.kt` | 本地存储；账号作用域键 `ACCOUNT_SCOPED_KEYS` / `scopedKey` / `migrateSingleAccountData`；小组件开关 `widgetOn`、形态 `widgetForm` |
| `SecretStore.kt` | 密码的本地加密存储（AndroidKeyStore 生成密钥，AES-256-GCM，按学号分账号） |
| `Diag.kt` | 本地诊断：**只记「时间 + 位置 + 异常类名」，绝不记异常消息**（消息里可能带学号） |
| `Theme.kt` | 配色：`Palettes`（light / dark）+ 全局 `C` + 按课程名稳定取色的 `CourseColors` |
| `MainActivity.kt` | 入口 |

## 三、桌面小组件

- **两种形态，同一个组件**：宽度 < `WIDE_MIN_DP`（180dp）走 `widget_board_small.xml`（2×2：今天还剩几节 + 下一节），否则走 `widget_board.xml`。是拖出来的尺寸分支，不是两个组件。`widget_info.xml` 里 `targetCell 4×2`（Android 12+ 的默认落位）、`minWidth 180dp`、`minResizeWidth/Height 110dp`（老启动器默认也是 4×2，但能拖到 2×2）。
- **内容**：`widgetState(tt, now, maxRows)` 算「第几周 / 日期星期 / 学期进度·距放假 / 今天课表 / 下一节 / 空状态」；2×2 用 `smallState()`。渲染层只上色，不含判断。
- **行数与字号**：`widgetRowsFor(heightDp, hasEcho)` 按高度给课表行数；回声洞正文与 2×2 课名用「`layout_weight=1` 吃掉余下高度 + `autoSizeTextType=uniform`」自动缩字号，长句不会被两行截断。
- **刷新时机**：App 侧 `HaueWidget.refresh()`（课表变化 / 换主题 / 登录 / 切号 / 退出）+ 拖尺寸（`onAppWidgetOptionsChanged`）+ 闹钟（今天每节课**结束**、下一节课**开始**、次日零点、每半小时兜底）。不用 `updatePeriodMillis`。
- **渲染与开销**：渲染走同伴对象里的单线程 `worker`；`refresh()` 用 `AtomicBoolean` 合并突发调用，并保证「运行期间又有变化会补跑一次」。每轮开始时只算一次内容（课表状态按实例高度缓存在 `stByHeight`），故障动画的四帧直接复用；要播动画时不先推完整内容——最后一帧就是正片，先推必被覆盖。没有课表数据时撤掉全部闹钟。
- **不做无谓的重排（性能）**：闹钟都是绝对时刻，**日期 / 课表 / 实例尺寸都没变就不调 `reschedule()`**（`lastReschedKey` 把关）。回声洞每 5 秒进来渲染一次，不拦的话每次都是十几个 `cancel + set` 的 binder 往返。关掉小组件时把 key 清空，保证重新打开能重新武装。
- **配色**：正文 / 次要 / 强调色直接取 `Palettes.xxx.toArgb()`，不手抄十六进制。只有背景两色落在 `res/values/colors.xml`（圆角只能靠 shape drawable）。
- **开关**：`prefs.widgetOn` 关掉时整条渲染走 `buildOff()`——先 `cancelAll()` 撤掉全部闹钟，再用简版布局画一句「小组件已关闭」。
- **画法与实际尺寸是两件事，界面文案不能混**：`prefs.widgetForm` 只决定**画法**（`auto` 看桌面给的实际宽度，`widgetIsSmall()`；`wide` / `small` 固定一种）。**桌面那块的实际大小应用改不了**——安卓没有这个公开接口（`requestPinAppWidget` 的 extras 只支持预览图，不含尺寸）。唯一沾边的是 `updateAppWidgetOptions`（`HaueWidget.resize()`），把 min/max 宽高交给启动器：**实测华为 / 荣耀桌面不认**（请求后桌面节点包围盒 998px 分毫未变），AOSP 桌面据文档会照办，所以它只是 best-effort，不能写成「点了就会变小」，正确说法是「长按卡片拖边角」。
- **面板上「现在几格」读渲染路径自己记下的尺寸**（`prefs.lastWidgetSize`，`logSizes()` 在尺寸变化时写入），**别用 `getAppWidgetOptions` 现读**：已从桌面卸载、但宿主尚未释放的实例会留下残留值——实测读到 110×110（2×2），而屏幕上明明是 4×2。
- **隐私**：`widgetCategory="home_screen"`，不进锁屏；卡片上不出现姓名 / 学号；回声洞正文只走 `setTextViewText`，不给它挂任何点击或跳转。
- ⚠️ **别按资源文件名找小组件布局**：R8 会把磁盘文件名混淆（`layout/widget_board` → `res/HN.xml`）。核对包内资源要用 `aapt2 dump resources` 按资源表条目名查。

### 回声洞的换句节奏

- 一条句子从**整句完整显示出画面**起停 `Echo.HOLD_MS`（5 秒），再换下一条。**不是固定间隔定时器**。总周期 = 故障帧 `(帧数-1) × Echo.FRAME_MS` + 5 秒。
- 每次渲染都重排同一个 `ACTION_ECHO` 闹钟（先 cancel 再 set，用 `RTC` 不叫醒设备），所以闹钟被系统吞掉、进程被杀、手机重启之后，都会在下一次任何触发里重新接上。
- 帧数由 `ECHO_BODY`（布局里的正文槽位）决定，节奏自动跟着变：加帧只改布局 + `Echo.frames()`，不用改时间常量。
- 关掉回声洞、或文件里没有句子时**不排闹钟**（空文件只显示一句提示，不值得每 5 秒白刷一次）。

### 回声洞的 jwzs.txt

- **默认内容**：`app/src/main/assets/jwzs.txt`（打进 APK）。想把自己的句子并进默认内容，改这个文件提 PR 即可，不用动代码。
- **用户自己的**：`Android/data/com.cxywh.hauejw/files/jwzs.txt`（应用私有外部目录，其他 App 读不到）。有这个文件就优先用它，删掉即回到内置默认。App 内「常用功能 → 回声洞」读写的就是它。
- **格式**：`"正文";`。引号里才是正文；分号或换行断句；中英文引号（`""`、`“”`、`‘’`、`「」`、`『』`）与中英文分号都认；同一对引号的两个字符互认（写反也认）；整句一个引号都没有就整句照显；引号不闭合也能取到内容。
- **容量上限**：文件最多读 256KB（`MAX_FILE_BYTES`），单句截到 2000 字加省略号（`MAX_STATEMENT_CHARS`），读满上限时掐掉截断处的半个 UTF-8 字符——不掐的话严格解码整篇失败、退到 GBK 就成乱码。
- **写入也有上限（安全）**：`Echo.save(ctx, text)` 用同一个 `MAX_FILE_BYTES` 上限截断，复用读取时那套「别截在半个字上」的处理，返回是否截过、编辑界面据此提示。读取端有上限而写入端没有，用户会以为存进去了、其实尾巴永远读不回来。
- **挑句**：一轮内不重复（洗牌后按顺序发），重洗时避开刚显示过的那句，条数变了自动重洗。

```bash
# 核对小组件资源确实打进包了
$ANDROID_HOME/build-tools/35.0.0/aapt2 dump resources app-release.apk | grep -A2 widget
```

## 四、成绩与 GPA（0.2.0 新增）

- **口径刻意保守**：`加权 GPA = Σ(绩点×学分) ÷ Σ学分`，只用**学校自己给出 `jd > 0`** 的成绩行，不替学校补算绩点。学校没给绩点的课程（多是等级制）只计学分、不进 GPA；`jd = 0.0`（真不及格）**计入分母**，不会被悄悄跳过。
- **累计全部学期**要逐个学年学期拉（最多 12 次请求），所以做成**用户主动触发 + 显示进度**，不在打开面板时自动跑。它跑在面板的 `rememberCoroutineScope()` 上，面板关掉即取消。
- 数字格式化统一 `Locale.US`（`String.format` 默认跟系统地区，土耳其等地会把小数点显示成逗号）。

## 五、接口映射（逆向自站内 JS，已用 `verify_app_requests.py` 实跑核对）

| 用途 | 请求 |
|---|---|
| 登录页（拿 csrftoken + 隐藏字段） | `GET /jwglxt/xtgl/login_slogin.html` |
| RSA 公钥（base64 的 modulus / exponent） | `GET /jwglxt/xtgl/login_getPublicKey.html?time=<ms>` |
| 提交登录 | `POST /jwglxt/xtgl/login_slogin.html`，`yhm` + `mm`(RSA/PKCS#1v1.5 密文 base64) + `csrftoken` + 隐藏字段 |
| 校历（学期起止） | `GET /jwglxt/xtgl/index_cxAreaFive.html?gnmkdm=index` |
| 课表页（取表单隐藏字段） | `GET /jwglxt/kbcx/xskbcx_cxXskbcxIndex.html?gnmkdm=N2151` |
| 课表数据 | `POST /jwglxt/kbcx/xskbcx_cxXsgrkb.html`（`xnm`/`xqm`/`gnmkdm`/`page=1`/`rows=5000` + 页面的隐藏字段） |
| 成绩 | `POST /jwglxt/cjcx/cjcx_cxDgXscj.html?gnmkdm=N305005`，`doType=query` |
| 考试 | `POST /jwglxt/kwgl/kscx_cxXsksxxIndex.html?gnmkdm=N358105`，`doType=query` |
| 退出 | `GET /jwglxt/xtgl/login_logout.html` |

**通用规律（省得每次去翻 JS）**：正方 v5 的 jqGrid 内页，**POST 页面自身的地址 + `doType=query`** 就是它的数据接口，不用去找 `*_List.html`。
- 空响应 = 会话过期（**不是**返回登录页），补登后重试；不带 `doType` 会 404。
- 响应 `Connection: close`（不复用长连接），每次请求都重新建 TCP。
- 实测耗时：登录 POST 约 1.4 s、首页 0.8 s、课表页 0.5 s——学校服务器本身就慢，客户端激进没有收益。

`xqm`：`3`=第一学期，`12`=第二学期，`16`=第三学期。学年学期先按校历取，失败再按当前月份推算（8 月前算上一学年），所以不用每年改代码。

**课表 JSON 字段**：`kcmc`课程名、`xm`教师、`cdmc`教室、`xqmc`校区、`xqj`星期、`jcs`节次、`zcd`周次段、`xf`学分、`kclb`类别、`kcxz`必修/选修、`khfsmc`考核、`jxbzc`教学班；集中实践在 `sjkList`；学籍在 `xsxx`。

### 选课（仅勘察结论，未实现）

`GET /jwglxt/xsxk/zzxkyzb_cxZzxkYzbIndex.html?gnmkdm=N253512&layout=default`

- 路径可达。**选课窗口外**，服务端直接在返回的 HTML 里写「对不起，当前不属于选课阶段」——此时页面**零个 XHR**，查不到任何数据请求，所以真实字段（容量 / 已选人数）必须在开窗期间抓。
- 页面主脚本是 `xsxk/zzxkyzb.js`（约 66 KB），数据接口地址写在里面。
- 同一账号只能有一处活跃会话（多会话会互踢）。
- App 里「常用功能 → 学校菜单入口」能看到学校返回的全部菜单项，选课地址就在其中。

## 九、注意与红线

- 全站 HTTP 明文，学号在链路上是明文。这是学校服务器的既有情况，App 无法改变。
- 密码只在登录那一刻用 RSA 加密后提交；勾选「记住密码」才用 Keystore 派生的密钥加密存本机，不勾选则从不落盘。**会话 Cookie 不落盘**，过期时用本机密码静默重登。
- 诊断只记时间 / 位置 / 异常类名，不记异常消息（消息里可能带学号）。
- App 只读数据（课表 / 成绩 / 考试），不向学校系统提交任何修改。
- 发布产物里**不得**出现学号、姓名；签名密钥（`keystore/`、`keystore.properties`）**不得**入库。
- `versionCode` 必须单调递增（升级判据），对外 `versionName` 按语义走。
