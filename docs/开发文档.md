# 教务助手（HAUEJW）

河南工程学院教务系统的安卓客户端。Kotlin + Jetpack Compose，单 APK 约 950 KB。

- 包名：`com.cxywh.hauejw`（debug 版为 `.debug` 后缀，可与正式版共存）
- 版本：1.0.0（versionCode 1）
- minSdk 26（Android 8.0+），targetSdk 35（Android 15）
- 目标站点：`http://124.system.haue.edu.cn/jwglxt/`

---

## 一、已实现

### 1. 课表（按参考图的版式）
- 顶部标题栏 + 右侧 `···` 菜单
- 黄色横幅：点我设置【课前提醒】
- 紫色周次胶囊 `第N周 ▾` + 学期名 + 学生姓名/班级 + 刷新
- 日期条：`X月` + 周一~周日（今天高亮黄底，可点选某一天）
- 网格：左侧「节次 + 起止时间」（1 08:30-09:15 … 8 16:45-17:30），右侧 7 天
- 课程卡片：`课程名` + `@ 校区教室`，同一门课颜色固定（浅色系，7 色轮转）
- 点卡片 → 详情（教师 / 教室 / 节次 / 周次 / 学分 / 类别 / 考核 / 教学班）
- 集中实践课（整周）单独一行提示
- 底部：`＋ 添加/更新课表` ｜ `≡ 常用功能`

### 2. 周次切换弹层
- 1…N 周按每行 5 个排布，当前周黄底，本周额外标「本周」
- 底部「查看本学期全部课程」

### 3. 常用功能直达（WebView）
成绩查询 / 自主选课 / 考试信息 / 个人课表 / 个人信息 / 培养方案 / 学籍预警 / 重修报名

**已在 App 内完成登录，打开时把 `JSESSIONID` 注入 WebView**，所以点进去就是登录态，不用再登一次。

### 4. 其它
- 登录页：学号 + 密码（RSA 加密后提交），记住学号，密码不落盘
- 课表本地缓存：断网/进不去时显示上次的课表，并在顶部提示
- `···` → 网络自检：逐项测登录页 / 公钥接口 / 会话 / 课表页耗时，用来判断"是网络慢还是学校服务器慢"
- `···` → 课前提醒设置（开关 + 提前 10/20/30/45 分钟；设置项已保存，通知调度尚未接线）
- 网络：只放行 `haue.edu.cn` 的明文 HTTP（network_security_config），其它一律禁止明文

## 二、安装

**方式一（推荐，你已有 LocalSend）**：把 `dist/教务助手-1.0.0.apk` 用 LocalSend 传到手机，点安装。

**方式二（USB 调试）**：双击 `安装.bat`，或
```bash
adb install -r "dist/教务助手-1.0.0.apk"
```

APK 已用 `keystore/hauejw.jks` 签名（V2+V3），DN：`CN=HAUEJW`。
换签名要卸载重装；`keystore.jks` + `keystore.properties` 别提交到公开仓库。

## 四、接口映射（逆向自站内 JS，与桌面端脚本一致）

| 用途 | 请求 |
|---|---|
| 登录页（拿 csrftoken + 隐藏字段） | `GET /jwglxt/xtgl/login_slogin.html` |
| RSA 公钥（base64 的 modulus/exponent） | `GET /jwglxt/xtgl/login_getPublicKey.html?time=<ms>` |
| 提交登录 | `POST /jwglxt/xtgl/login_slogin.html`，`yhm` + `mm`(=RSA/PKCS#1v1.5 密文 base64) + `csrftoken` + 隐藏字段 |
| 校历（学期起止） | `GET /jwglxt/xtgl/index_cxAreaFive.html` |
| 课表页（取表单隐藏字段） | `GET /jwglxt/kbcx/xskbcx_cxXskbcxIndex.html?gnmkdm=N2151` |
| 课表数据 | `POST /jwglxt/kbcx/xskbcx_cxXsgrkb.html`，`xnm`/`xqm`/`gnmkdm`/`page=1`/`rows=5000` |
| 退出 | `GET /jwglxt/xtgl/login_logout.html` |

`xqm`：`3`=第一学期，`12`=第二学期，`16`=第三学期。
脚本会先试校历给出的学年学期，失败再按当前月份推算的学年兜底（8 月前算上一学年），所以不用每年改代码。

**课表 JSON 用到的字段**：`kcmc`课程名、`xm`教师、`cdmc`教室、`xqmc`校区、`xqj`星期、`jcs`节次、`zcd`周次段、`xf`学分、`kclb`类别、`kcxz`必修/选修、`khfsmc`考核、`jxbzc`教学班；集中实践在 `sjkList`（`jsxm`/`qsjsz`）；学籍在 `xsxx`（`XM`/`XH`/`BJMC`/`XNM`/`XQM`/`XNMC`）。

## 五、改哪里

| 想改什么 | 改哪 |
|---|---|
| 节次与上课时间 | `WeekUtils.kt` 里的 `Slots.ALL`（默认按参考图：08:30–17:30 × 8 节） |
| 常用功能列表 | `MainActivity.kt` 里的 `DirectLinks.ALL` |
| 配色 | `Theme.kt`（`C` / `CourseColors`） |
| 网格行高、卡片字体 | `GridMetrics.slot`（默认 56dp） |

构建：
```bash
cd D:/work/HAUEJW
./gradlew.bat assembleDebug        # 调试包
./gradlew.bat assembleRelease      # 正式包（R8 压缩，需 keystore.properties）
```
Windows 上如果 release 报 `classes.dex 另一个程序正在使用`：`./gradlew.bat --stop` 后删 `app/build/intermediates/dex/release` 再构建。

## 七、注意

- 全站 HTTP 明文，学号在链路上是明文。这是学校服务器的既有情况，App 无法改变。
- 密码只在登录那一刻用 RSA 加密后提交，不写入本地存储。
- 课表数据来自学校接口，App 只做展示与直达，不篡改任何提交内容。
